Group project repository for **Anas, Hasan, and Aaron**.

## Contents

- `Phase1_Student_Dropout_Template.ipynb` — bare Phase I template covering Tasks 1–4 (problem/dataset, acquisition & inspection, cleansing & transformation, EDA).

## Phase I scope

Problem definition, dataset documentation, Python loading/inspection, cleaning/transformations, and exploratory analysis. Machine-learning modelling is not required for Phase I.

## How to use

1. Fill markdown placeholders (`[enter ...]`).
2. Point the load cell at your approved dataset (keep raw data under `data/` if possible).
3. Replace TODO code stubs with justified project-specific steps.
4. Record lecturer approval status in Task 1.5.
